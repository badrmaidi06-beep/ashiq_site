موقع «عاشق من وراء الزمن» — بدر الدين
===========================================

هذه نسخة مطوّرة من المشروع الأصلي الذي أرسله الكاتب، وليست إعادة إنشاء من الصفر.
تم الإبقاء على تعريف الرواية العربي كما ورد حرفياً في النسخة السابقة، مع الاحتفاظ بنصوصه وصوره الأصلية.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `style.css` — الهوية البصرية والحركات والاستجابة للهاتف.
- `script.js` — اللغة، قائمة البلديات، العد التنازلي، تقدير السعر وإرسال النموذج.
- `config.js` — عنوان نقطة استقبال الطلبات فقط (لا تضع أي أسرار هنا).
- `assets/cover-front.png` / `cover-back.png` / `cover-spine.png` — صور مستخرجة من ملف PDF الأصلي.
- ملفات WebP — نسخ أخف للعرض السريع على الويب.
- `netlify/functions/order.js` — نقطة استقبال الطلبات وإرسالها بالبريد عبر Resend.
- `netlify.toml` — إعداد Netlify Function.

## معاينة الموقع محلياً

لا تفتح `index.html` بالنقر المزدوج لأن المتصفح قد يمنع تحميل بيانات البلديات من مصدر خارجي.

1. فك ضغط ZIP.
2. افتح Terminal / PowerShell داخل المجلد.
3. شغّل:

   `python -m http.server 8080`

4. افتح `http://localhost:8080` في المتصفح.

تظهر شاشة الافتتاح السينمائية أولاً. انقر عليها أو انتظر حتى تختفي.

## الطلبات والبريد — مهم

**النموذج لا يرسل الطلبات في وضع المعاينة** حتى لا تُجمع بيانات الزوار دون إعداد واضح. الحسابات أو مفاتيح البريد لا توضع داخل JavaScript أو ملفات الواجهة.

### إعداد استقبال الطلبات بأمان على Netlify

1. اربط هذا المشروع بموقع Netlify (يمكن ربطه بمستودع GitHub).
2. أنشئ حساباً في Resend وتحقق من نطاق بريد الإرسال.
3. في Netlify → Site configuration → Environment variables، أضف:
   - `RESEND_API_KEY` — المفتاح السري من Resend.
   - `ORDER_EMAIL` — البريد الذي يستقبل الطلبات.
   - `FROM_EMAIL` — بريد الإرسال المعتمد في Resend، مثل `Reservations <orders@your-domain.com>`.
   - `ALLOWED_ORIGIN` — عنوان الموقع المنشور كاملاً، مثال `https://your-site.netlify.app`.
4. في `config.js` غيّر `orderEndpoint` إلى:
   `"/api/order"`
5. أعد نشر الموقع. جرّب طلباً تجريبياً ثم تحقق من وصول البريد.

تُرسل الطلبات عبر وظيفة خادمية إلى Resend. لا يتم تضمين مفتاح Resend في المتصفح. لا تُفعّل النموذج قبل ضبط متغيرات البيئة وعنوان البريد وموافقة صاحب الموقع على معالجة بيانات الطلب.

### استضافة GitHub Pages

GitHub Pages يستضيف ملفات الواجهة الثابتة فقط ولا يشغّل Netlify Functions. يمكنك إبقاء GitHub Pages للواجهة وربط `orderEndpoint` بعنوان خادم HTTPS مستقل يدعم استقبال الطلبات (مثل Netlify Function منشورة منفصلة). لا تضع المفتاح السري في GitHub Pages أو `config.js`.
